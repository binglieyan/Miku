# 如何添加背景音乐

本壁纸**不附带任何音频文件**，但播放器已经写好并常驻启用。你只需要把一首
自己的音乐放进这个文件夹、改名成 `bgm.flac`，它就会自动循环播放。

> ## ⚠️ 仅支持 `.flac` 格式
>
> **本壁纸只播放 `.flac` 音频文件。** mp3、m4a、wav、ogg、aac 一律不行——
> 文件名改了也不会响，因为播放器的路径是写死的 `music/bgm.flac`。
>
> 你手上的音乐如果是 mp3 之类的格式，**先转成 flac 再放进来**，转换方法见
> [下面](#格式要求只认-flac)。这是唯一需要额外做的一步。

一共四步，大约一分钟。

---

## 第 1 步：找到壁纸文件夹

**已订阅的创意工坊壁纸**（绝大多数情况）

1. 打开 Wallpaper Engine，在「已安装」列表里选中这张壁纸
2. **右键 → 在资源管理器中打开**

打开的路径形如：

```
...\Steam\steamapps\workshop\content\431960\3755473060\
```

**自己下载的壁纸包**

就是你解压后放着 `index.html` 的那个文件夹，直接打开它。

进去之后应该能看到 `index.html`、`images`、`js`、`music` 这几项。

## 第 2 步：把音频放进 `music` 文件夹

把**已经转好格式的 `.flac` 文件**拖进 `music` 文件夹。文件名此刻还能随便叫。

## 第 3 步：改名成 `bgm.flac`

改成 **`bgm`**，扩展名必须是 **`.flac`**。

改完应该是这样：

```
music\
└── bgm.flac
```

> ### ⚠️ 这一步失败率最高，原因只有一个
>
> Windows 资源管理器默认**隐藏已知文件扩展名**。此时你把文件改名成 `bgm`，
> 系统实际得到的是 `bgm.mp3`，扩展名还是 mp3，壁纸依然不出声——而且你从
> 文件名上看不出区别。
>
> **先打开扩展名显示**：资源管理器 →「查看」→ 勾选「文件扩展名」
> （Windows 11 在「查看 → 显示 → 文件扩展名」）。
>
> 打开后你会看到 `bgm.mp3` 这样的完整名字，这时再改成 `bgm.flac`。
> 如果弹窗问「如果改变文件扩展名，可能会导致文件不可用」，选**是**。

## 第 4 步：让壁纸重新加载

音频是在页面加载时读取的，改完文件必须重载一次：

- 在「已安装」里**切换到别的壁纸，再切回来**；或者
- 重启 Wallpaper Engine。

然后打开壁纸的**属性面板**，确认：

- 「播放背景音乐（需自备 bgm.flac）」被**打开**——它**默认是关的**，因为壁纸
  本身不带音乐，不打开就不会去读文件
- 「背景音乐音量」不是 0（默认 35）

---

## 格式要求：只认 `.flac`

| 格式 | 能否播放 | 怎么办 |
|---|---|---|
| **`.flac`** | ✅ | **直接改名成 `bgm.flac` 即可，不用改任何代码** |
| `.mp3` | ❌ | 先转成 flac |
| `.m4a` / `.aac` | ❌ | 先转成 flac |
| `.wav` | ❌ | 先转成 flac（还能顺便把体积降下来） |
| `.ogg` / `.opus` | ❌ | 先转成 flac |
| 32-bit / float 编码的 flac | ❌ | 转成 16-bit 或 24-bit |

**为什么是 flac**：它是开放的、无损的编解码器，Windows 和 Wallpaper Engine 用的
浏览器内核都必定带解码器，不像 mp3/aac 在某些精简构建里会缺授权解码器。

### 怎么转成 flac

**用 ffmpeg（一行命令，最省事）**

```bash
ffmpeg -i "你的音乐.mp3" "bgm.flac"
```

**用图形界面工具**

- **Foobar2000**：右键曲目 → Convert → 选 FLAC
- **格式工厂 / Format Factory**：选「音频 → FLAC」
- **Audacity**：打开音频 → File → Export → Export as FLAC

转完把产物改名成 `bgm.flac` 放进 `music\` 即可。

> **体积提醒**：flac 是无损的，同长度约为 320 kbps mp3 的 5–10 倍，4 分钟的
> 曲子大约 20–40 MB。如果嫌大，可以转成 16-bit / 44.1 kHz 的 flac，体积能小
> 一些但音质损失可以忽略。

**位深要求**：16-bit 或 24-bit、44.1 或 48 kHz 是安全区间。32-bit 浮点编码的
flac 解码不了，表现是控制台出现一次
`[audio] 音频加载失败（MediaError code …）`、壁纸静音但其它一切正常。

## 没声音？按这个顺序查

| 现象 | 原因 | 处理 |
|---|---|---|
| 完全没声音，放的是 mp3 / m4a / wav | **格式不对，只支持 flac** | 转成 flac，见上一节 |
| 完全没声音，文件名看着是对的 | 扩展名没显示，实际是 `bgm.flac.mp3` 或 `bgm.mp3` | 打开扩展名显示，重新改一次 |
| 完全没声音，文件确实是 `bgm.flac` | 没有重载页面 | 切到别的壁纸再切回来 |
| 完全没声音，上面都对 | 「播放背景音乐」没打开（**默认是关的**），或音量是 0 | 属性面板里打开它、拉高音量 |
| 声音很小 | 默认音量 35 | 属性面板拉高音量 |
| 控制台出现 `[audio] 音频加载失败（MediaError code …）` | 32-bit float flac，或文件损坏 | 转成 16/24-bit flac；code 3 是解码失败，code 4 是文件不存在/格式不支持 |
| 更新壁纸后音乐没了 | Workshop 更新会**整体重装**作品文件夹，你放进去的文件被覆盖 | 重新放一次，见下 |

---

## 两个要提前知道的事

**1. Workshop 更新会冲掉你的音乐**

订阅的壁纸在作者更新时，Steam 会把整个作品文件夹重新下载一遍。你放进去的
`bgm.flac` 不在更新包里，会被删掉。每次壁纸更新后重新放一次即可。

**2. 版权**

`bgm.flac` 由你自己提供，不随壁纸分发，所以不涉及任何随作品再分发的问题。
但**你放什么、在什么范围内使用**仍由你负责：本地自己听没有限制；如果你要把
自己的整个壁纸文件夹二次分享给别人，那就得先确认你有这首曲子的分发权。

## 给开发者

- 音源路径是**硬编码**的 `music/bgm.flac`，唯一的定义点在 `index.html`：
  `<audio id="bgm" src="music/bgm.flac" loop preload="none">`。所以面向用户的
  文档统一宣称"仅支持 flac"——多格式支持意味着让用户改代码，不值得。
  真要换成其它格式，改这一行 `src`，并同步 `music/README.md` 与
  `project.json` 的 `description`（三处必须一致）。
- `preload="none"` 不能改回 `auto`：包内无音频时，`auto` 会在解析 HTML 阶段就
  去抓 `bgm.flac`，浏览器固定打一条 404，而那条日志是网络层打印的，JS 拦不住。
  配合开关默认关闭，才能做到"没放音乐时控制台干净"。
- 用浏览器直接打开 `index.html` 调效果时，没有引擎回传属性、音乐开关会一直是
  关的（这是刻意的，见上一条 `preload`）。加 `?bgm=on` 只是把开关置为开；
  能否真正出声仍取决于浏览器的自动播放策略。
- 循环由 `<audio loop>` 交给浏览器，音频本身最好做成首尾能自然衔接的片段；
  普通歌曲硬循环会在接缝处听出一次断裂。
- Wallpaper Engine 宿主放行自动播放，正常不需要用户手势；只有普通浏览器预览
  或其他受限宿主可能被策略拦截。`js/audio.js` 为此保留静默退避重试（1s → 30s
  封顶），并在壁纸页面收到点击/按键、窗口重新聚焦或重新可见时再试。
  属性面板的点击不是页面手势。
- 文件缺失或解码失败时 `error` 事件会停止重试并提示一次（带 `MediaError`
  code），壁纸的其它部分不受影响。
- 本目录的音频被 `.gitignore` 忽略（只保留这份说明），不会随仓库一起分发。
  自己创作或 CC0 的曲子若想入库，删掉 `.gitignore` 里 `music/*` 与
  `!music/README.md` 两行即可。
- 本说明文件可以删除。
